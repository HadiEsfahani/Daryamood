# سایت نمایش قیمت روزانه

## ساختار
```
[سایت‌های مبدأ]
      │
      ▼ (اسکریپت پایتون روزانه اجرا می‌شود)
[GitHub Actions (رایگان)] ───► ذخیره در فایل prices.json
      │
      ▼
[صفحه ساده HTML/JS روی GitHub Pages]
```

- `scraper.py` → قیمت‌ها را از سایت‌های مبدأ می‌خواند و در `prices.json` می‌نویسد.
- `.github/workflows/update-prices.yml` → هر روز به‌صورت خودکار `scraper.py` را اجرا می‌کند.
- `index.html` → همان فایل `prices.json` را می‌خواند و همه‌ی قیمت‌ها را زیر هم نشان می‌دهد.

## راه‌اندازی (یک‌بار)

۱. یک ریپازیتوری جدید در گیت‌هاب بسازید و همه‌ی این فایل‌ها را در آن push کنید.

۲. اجازه‌ی نوشتن به Actions بدهید تا بتواند خودش `prices.json` را کامیت کند:
   Settings → Actions → General → Workflow permissions → گزینه‌ی
   **"Read and write permissions"** را انتخاب کنید و Save بزنید.

۳. GitHub Pages را فعال کنید:
   Settings → Pages → Branch: `main` (یا `master`) → Folder: `/ (root)` → Save.
   بعد از چند دقیقه آدرس سایت شما به شکل زیر در دسترس خواهد بود:
   `https://<username>.github.io/<repo-name>/`

۴. برای اینکه همین الان یک‌بار قیمت‌ها را بگیرد (بدون صبر کردن تا فردا):
   تب Actions → روی workflow با نام "Update Prices" کلیک کنید → دکمه‌ی
   **Run workflow** را بزنید.

از این به بعد، هر روز به‌صورت خودکار قیمت‌ها بروزرسانی و روی سایت نمایش داده می‌شوند.

## نکات مهم

- **آهن‌آنلاین**: قیمت‌ها از جدول‌های صفحه‌ی دسته‌بندی خوانده می‌شوند. کد طوری نوشته
  شده که به‌جای وابستگی به کلاس‌های CSS، از روی متن سرستون‌ها ("نام"، "قیمت")
  ستون‌های مورد نیاز را پیدا می‌کند؛ این باعث می‌شود در برابر تغییرات جزئی ظاهر
  سایت مقاوم‌تر باشد، اما اگر سایت ساختار جدول را کاملاً عوض کند، ممکن است لازم
  باشد `scraper.py` بروزرسانی شود.

- **لوله‌آنلاین**: این سایت در فایل `robots.txt` خود اجازه‌ی دسترسی خودکار
  (کرالر/ربات) را نمی‌دهد. این یعنی:
  - از نظر فنی، `requests` معمولاً همچنان می‌تواند صفحه را بگیرد (چون robots.txt
    فقط یک "درخواست مؤدبانه" است، نه یک قفل فنی)، و اسکریپت طوری نوشته شده که
    تلاش می‌کند قیمت را با چند روش مختلف پیدا کند.
  - اما اگر سایت با متد فنی (مثل مسدود کردن IP سرورهای گیت‌هاب یا نیاز به
    اجرای جاوااسکریپت برای بارگذاری قیمت) از دسترسی جلوگیری کند، ممکن است این
    منبع در `prices.json` خالی بماند. در آن صورت لاگ اجرای Action (تب Actions)
    را چک کنید تا ببینید پیام خطا یا هشدار چیست.
  - بهتر است پیش از استفاده‌ی گسترده، شرایط استفاده (Terms of Service) سایت
    را هم بررسی کنید.

- اگر یک سایت مبدأ موقتاً از دسترس خارج باشد یا خطا بدهد، اسکریپت متوقف
  نمی‌شود؛ فقط آن منبع را با یک پیام هشدار در لاگ رد می‌کند و بقیه‌ی سایت‌ها
  را ادامه می‌دهد.

## اضافه کردن سایت جدید بعداً

در `scraper.py`، به لیست `SOURCES` یک آیتم جدید اضافه کنید و در صورت نیاز
یک تابع `parse_...` مخصوص ساختار همان سایت بنویسید (شبیه دو نمونه‌ی موجود).
